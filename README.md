# \# EWS Alerts

# 

# EWS (Early Warning System) alert and rule setup scripts.

# 

# This repository contains the SQL scripts and helper files required to set up and test EWS/FRM-related rules and alerts.

# 

# \## Repository Contents

# 

# \* `00\_foundation.sql` – Foundation/setup data

# \* `01\_inventory.sql` – Inventory-related data

# \* `02\_receivables.sql` – Receivables-related data

# \* `03\_default\_sma1.sql` – Default SMA1 rule/data

# \* `04\_quick\_sma.sql` – Quick SMA rule/data

# \* `05\_credit\_summation.sql` – Credit summation rule/data

# \* `run\_frm\_rule.bat` – Run FRM rule setup

# \* `run\_frm\_rule\_ui.bat` – Run FRM rule UI setup

# \* `run\_frm\_rule\_ui.ps1` – PowerShell script for FRM rule UI

# 

# \## Getting Started

# 

# Clone the repository:

# 

# ```bash

# git clone https://github.com/kishal-utterwise/ews-alerts.git

# ```

# 

# Go to the project directory:

# 

# ```bash

# cd ews-alerts

# ```

# 

# Run the required SQL scripts in the appropriate order for your environment.

# 

# \## Notes

# 

# \* Verify database connection/configuration before running the scripts.

# \* Review the SQL scripts before executing them in a shared or production database.

# \* Use the latest version from the `main` branch.
